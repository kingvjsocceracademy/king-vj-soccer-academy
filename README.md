# KING VJ SOCCER ACADEMY

Starter website for the academy. The site is a static HTML/CSS/JavaScript website suitable for GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and current year

## Before launch
Replace the placeholder phone number and email address in `index.html`. Confirm the academy's exact location, training schedule, registration process, and any fees before publishing those details.

## Publish with GitHub Pages
In the repository, open Settings → Pages. Under Build and deployment, select Deploy from a branch, choose `main` and `/ (root)`, then Save. Wait for GitHub Pages to publish the site.
